# MVC and application shells

Layout follows the user's current area rather than one global site layout.

```text
azunt.com/
├─ /                  PublicShell
├─ /docs/             DocsShell
├─ /dashboard/        DashboardShell
└─ /account/          AccountShell
```

Public, dashboard, and account pages are served by ASP.NET Core MVC. Public docs are generated by DocFX. Protected docs are rendered by MVC after authorization.

## Shell responsibilities

- Public pages handle site navigation and product content.
- Docs pages handle hierarchical documentation navigation.
- Dashboard pages handle authenticated application work.
- Account pages handle sign-in, registration, and profile actions.

Brand assets, authentication, and shared components can be moved to a Razor Class Library when reuse across projects is needed.
